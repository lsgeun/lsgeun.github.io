# 메모 시스템이 단순하면 생각과 행동이 풍부해진다

[[기존의 메모 시스템을 참고해 나만의 메모 시스템 구축#블로그 시스템 도입]]에서 언급한 것처럼, 나는 메모 시스템을 여러 번 갈아엎었다.

이렇게 여러 번 갈아엎으면서 알게 된 것은 시스템은 단순해야 한다는 것이다. 좋은 아이디어, 좋은 기능, 좋은 시스템 등을 적극 활용하려다가 오히려 시스템이 복잡해져서 관리하기가 어렵게 된다. 시스템이 단순하면, 나중에 시스템을 바꾸기도 편하고, 시스템을 적용하기도 편하다. 마치 레고 블럭과 비슷하다. 비슷한 규격의 단순한 블럭을 쌓아서 복잡한 구조물을 만들기 때문이다. 단순한 메모 시스템도 단순한 메모들을 서로 엮어서 복잡한 메모 구조를 만든다.

시스템이 복잡하면, 메모에 집중되는 것이 아니라, 시스템의 규칙, 시스템의 인프라 등 메모가 아닌 것에 더 집중하게 되는 거 같다. 메모 시스템을 단순화하면 메모에 훨씬 더 집중이 되는 거 같다. 메모를 어떻게 작성해야 할지, 메모를 어떻게 엮어야 할지 등에 신경쓰다보니, 생각이 풍부해지고, 행동이 다양해지는 거 같다.

# 블로그 시스템도 단순한 시스템

그리고 단순한 시스템의 효과가 좋다는 것을 알게 되니, 필요할 거 같은 시스템을 단순화해서 가지고 오는 것에 신경이 쓰이고, 관심이 간다.

[[기존의 메모 시스템을 참고해 나만의 메모 시스템 구축#블로그 시스템 도입]]에서 말했지만, 옵시디언으로 블로그 글을 만들고, 블로그 서버에 배포하는 시스템도 단순화된 시스템이다. [jackyzha0/quartz](https://github.com/jackyzha0/quartz)라는 깃헙 리포지토리를 이용해서 만드는 것이고, 공식 홈페이지([Welcome to Quartz 5](https://quartz.jzhao.xyz/))에서 여러 기술들을 살펴보고, quartz 기반 블로그([hayoung blog](https://khy07181.github.io), [Welcome to Gurumii Lab](https://gurumii.com/))를 많이 참조하고, gemini에게 자문을 구해서 지금의 블로그를 만들게 되었다.

단순한 블로그 시스템에서는 그냥 옵시디언에서 블로그 글을 작성하고, 명령어 하나만 실행하면 블로그에 글이 배포가 된다.

# 단순화한다는 건 어렵다

하지만, 단순화한다는 것은 어렵다. 기존의 시스템들의 특징을 잘 추상화해서, 하나의 무언가로 만드는 과정이 필요하기 때문이다. 기존 시스템들의 특징을 잘 파악하고 있어야 하고, 내가 원하는 바를 잘 알고 있어야 단순한 무언가가 나온다.
